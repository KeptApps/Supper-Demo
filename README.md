# Supper public demo by KeptApps

Six sample recipes, a three-dinner planner and generated grocery list.
Open index.html locally or publish this folder using GitHub Pages.

## Publish
Upload index.html, meal.jpg, README.md and .nojekyll to the root of a new public repository named supper-demo. In Settings > Pages choose Deploy from a branch, main and /(root), then Save. Use the actual address GitHub provides after deployment.

If the account is keptapps and the repository is supper-demo, the expected address is https://keptapps.github.io/supper-demo/ . This is an expected address, not confirmation of deployment.

## Shop button
Both shop buttons point to https://www.etsy.com/shop/KeptApps . Replace both occurrences of that exact URL in index.html with your Supper listing URL when the listing is live.

## Scope
No account, persistence, analytics, external script, full recipe collection, paywall or checkout. Refresh resets the demo. No full-product download is included. Print uses the browser print dialog. This public source is visible to visitors.

## Files to keep private
Do not add the seller's full Supper app, buyer ZIP, backups, or full source to this repository. Publish only the supplied public demo files.

GitHub reference: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site
